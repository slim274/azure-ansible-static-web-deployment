# Adding this documentation to your existing project

1. Extract this ZIP to a temporary directory.
2. Inspect `screenshots/` and redact private details before publishing.
3. Back up your existing `README.md` before replacing it.
4. Copy `README.md`, `docs/`, `diagrams/`, and `screenshots/` into the matching **original Assignment 3 project**.
5. Keep actual Terraform/Ansible/application files in their original directories; this ZIP intentionally does not supply replacements.
6. Run a Git staged-file security review before committing and pushing.

Recommended GitHub repository name: `azure-ansible-multiplay-web-deployment`.
